# Ariafier
My friend Aria (who's not a programmer) kept suggesting that I type 7s into my
code to make it better. So, I did the next best thing and wrote a tool that can
turn all of my code (or any file!) into 7s.

## How does it work?
For every bit in the file, a 1 is an ASCII '7', and a 0 is a space.
